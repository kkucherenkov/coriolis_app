# Internationalisation

No user-visible string may ship as a literal. Ever. Three platforms, three implementations — same discipline.

Default locale: `en`. Active locales are `en` + `ru` — every key in `en` **must** exist in `ru` (and every other registered locale). Missing translation is a bug, not a fallback.

## Web — `@nuxtjs/i18n` + SFC `<i18n>` blocks

Translations are **colocated with the component**:

```vue
<i18n lang="json">
{
  "en": { "title": "System health" },
  "ru": { "title": "Здоровье системы" }
}
</i18n>
```

```ts
// <script setup>
const { t } = useI18n({ useScope: 'local' });
```

- `{{ t('title') }}` — scoped keys. Same for toast messages, dialogs, ARIA labels.
- To embed a literal `@`, escape: `{'@'}` (vue-i18n linked-message syntax).
- `@app/ui` components **never** call `useI18n()` — receive translated strings via props.
- No top-level `apps/web/i18n/locales/` directory; registered locales in `nuxt.config.ts` describe language/name/code only.

## Mobile — `slang` with namespace files

Files: `lib/i18n/<namespace>_<locale>.i18n.json` — one file per `(namespace, locale)` pair.

Config (`slang.yaml`): `namespaces: true`, `string_interpolation: braces`, `enum_name: AppLocale`, `flutter_integration: true`.

Regenerate: `dart run slang` (or via `build_runner`). Output `strings.g.dart` + `strings_<locale>.g.dart` — never edit by hand, gitignored.

```dart
// main()
LocaleSettings.useDeviceLocale();
runApp(TranslationProvider(child: const ProviderScope(child: MyApp())));
```

`MaterialApp` gets `locale: TranslationProvider.of(context).flutterLocale` + `supportedLocales: AppLocaleUtils.supportedLocales`.

Consume: `context.t.<namespace>.<key>` — e.g. `context.t.common.appTitle`. No raw `Text('Overall')` — review blocker.

## Backend — `nestjs-i18n` with per-locale namespace files

Files: `apps/backend/src/i18n/<locale>/<namespace>.json`. One subdirectory per language, one file per module. Copied to `dist/i18n/` via `nest-cli.json` assets rule.

`I18nModule.forRoot` in `app.module.ts`: `I18nJsonLoader`, `fallbackLanguage: 'en'`, resolvers: `QueryResolver(['lang'])`, `HeaderResolver(['x-lang'])`, `AcceptLanguageResolver`.

```ts
const lang = I18nContext.current()?.lang;
throw new UnauthorizedException(
  this.i18n.t('realtime.signInRequired', lang ? { lang } : undefined),
);
```

Translation key: `<namespace>.<key>` (filename = namespace prefix).

**Error bodies** use RFC 9457 `application/problem+json` — `title` and `detail` stay English-canonical. `nestjs-i18n` is for server-generated strings clients pass through verbatim.

## Glossary — non-negotiable canon translations

When translating game-mechanic vocabulary, keep these mappings. They are sourced from the Russian ST3001 rulebook (the official translation Free League ships) and overrule any AI-suggested or "more natural" wording. Drift here will surface as canon-violation review blockers.

| English (PRD / API)            | Russian (canonical)                                          | Forbidden alternatives                                                                                   | Citation                     |
| ------------------------------ | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ---------------------------- |
| push (a roll)                  | вознесение молитв (Ликам) — "приносить молитву" / "молиться" | ❌ толкнуть, ❌ пуш, ❌ протолкнуть                                                                      | ГЛАВА 3 §«Вознесение молитв» |
| pushed (already)               | помолились / уже воззвали к Ликам                            | ❌ толкнули, ❌ запушили                                                                                 | ГЛАВА 3 §«Вознесение молитв» |
| reroll (the action)            | повторный бросок                                             | ❌ перебросить (the rulebook uses «бросить ещё раз» for the dice action; «повторный бросок» is the noun) | ГЛАВА 3 §«Вознесение молитв» |
| Mercy (face / icon)            | Владычица Слёз                                               | ❌ Лик Милосердия (calque)                                                                               | ГЛАВА 10 «Владычица Слёз»    |
| Faceless One                   | Лик-без-лика                                                 | ❌ Безликий (drops the article-marker)                                                                   | ГЛАВА 10 «Лик-без-лика»      |
| amplua (character role bucket) | амплуа                                                       | leave Russian as-is in en.json too if context demands; otherwise `concept`                               | ГЛАВА 2 «АМПЛУА И РОЛИ»      |
| role (within an amplua)        | роль                                                         | ❌ профессия                                                                                             | ГЛАВА 2 «АМПЛУА И РОЛИ»      |
| key skill                      | ключевой навык                                               | ❌ основной навык                                                                                        | ГЛАВА 2 «НАВЫКИ»             |
| Exhausted (condition)          | Истощён                                                      | ❌ Уставший, ❌ Утомлённый                                                                               | ГЛАВА 5 §«Условия»           |
| incapacitated (status flag)    | Небоеспособен                                                | ❌ Без сознания, ❌ Выведен из строя                                                                     | ГЛАВА 5 «Урон»               |
| prone                          | Лёжа                                                         | ❌ Падший                                                                                                | ГЛАВА 5                      |
| covered                        | В укрытии                                                    | ❌ Прикрыт                                                                                               | ГЛАВА 5 «Укрытие»            |
| Mystic Darkness                | Межзвёздная Тьма                                             | ❌ Мистическая Тьма (calque)                                                                             | passim                       |

The web `<i18n>` blocks are colocated, so there is no central JSON for translators to consult — this table is the translator's source of truth. When `t('rolls.cta.push')` lands in a Vue `<i18n>` block, ru must be «Воззвать к Ликам» / «Помолиться» (UI copy is shorter), never «Пуш» or «Толкнуть».
