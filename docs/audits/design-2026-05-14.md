# Design / UI audit — 2026-05-14

**Scope:** v1 surfaces only. Phase 8 (chat, GM-session realtime enhancements, presence, whisper, invite manager, share-link card, player session, sessions list) is deferred per session direction.
**Source of truth:** `Coriolis App-handoff.zip` (Claude Design export), extracted to `/tmp/coriolis-handoff/coriolis-app/`.
**Method:** four parallel agent passes — tokens, docs, components, surfaces.

---

## TL;DR

- **Tokens:** 5/8 files structurally aligned. `color.json` drift is 100% Phase 8 (defer). `typography.json` has a schema-level refactor — not Phase 8, blocks engineering and needs a decision now.
- **Docs:** project has zero of the handoff's cross-cutting docs (PATTERNS, CONTENT) and partial coverage of the rest. Material amount of v1-relevant content (state matrices, keyboard map, focus-ring contract, voice, lore lexicon) lives only in the handoff.
- **Components:** 4 critical v1 atoms missing (`AppPanelTitle`, `AppSwash`, `AppWordmark`, `AppSkillRow`). `AppButton` missing `secondary` + `mystic` variants — `mystic` blocks dice-roller fidelity.
- **Surfaces:** Dashboard / "The Bridge" not shipped — auth users are dropped on a flat character list instead. Wizard step inventory diverges between handoff (8 steps), web (7) and mobile (6). Mobile is missing ship sheet and the full combat tracker.

## 1. Tokens

`shadow.json`, `spacing.json`, `radius.json`, `motion.json`, `opacity.json`, `z-index.json` — **structurally aligned**; `diff -q` reports byte diffs but `jq -cS` canonical comparison is identical (whitespace/key-order only).

### 1.1 `color.json` — major drift (Phase 8 only)

| Token (handoff only)                   | Purpose                                      |
| -------------------------------------- | -------------------------------------------- |
| `color.brand-indigo.default` `#5B6BE0` | Phase 8 brand accent (whispers, focus rings) |
| `color.brand-indigo.soft` `#7B89EC`    | Phase 8 hover/link                           |
| `color.chat.bubble-author-bg`          | Phase 8 chat                                 |
| `color.chat.bubble-other-bg`           | Phase 8 chat                                 |
| `color.chat.system-fg`                 | Phase 8 chat                                 |
| `color.chat.whisper-accent`            | Phase 8 whisper stripe                       |
| `color.focus-ring`                     | Phase 8 a11y                                 |

Project-only (additive, harmless): `color.brand.brass-{50,100,300,400,800,900,950}` — Tailwind/Nuxt UI numeric stops.

**Verdict:** **defer** — every missing token is Phase 8.

### 1.2 `typography.json` — major drift (NOT Phase 8, action required)

Two **incompatible schemas**, not just different keys.

- Top-level namespace renamed `typography` → `type`.
- Handoff exposes atom scales: `font.size.{9..64}` (16 stops), `font.tracking.{normal,tight,04..30}`, `font.line-height.{tight..loose}`. Project has none of them.
- Handoff composite roles use `{font.size.X}` references; project inlines literal `fontSize: "18px"` strings.
- Role names diverge: `display-hero / display-title / display-section / numeric-stat` (handoff) vs `display-{xl,lg,md,sm} / mono-stat-{md,xl}` (project). Handoff has `body-default / body-small`; project has `body-{lg,md,sm}`.

**Recommendation:** pick one schema **before consumers diverge further**. The handoff schema (atom-refs + composite roles) is more maintainable; the project schema is what `pnpm design:build` currently emits CSS vars from. Migration is non-trivial — needs its own ticket.

### 3.2 Partial / cosmetic drift

- **`AppStarOrnament`** renders filled 16-point polygon; handoff is stroke-only overlapping rects + centre dot. Add `variant: 'outlined' | 'filled'` instead of separate `AppStarFilled`. `AppStarOrnament.vue:22,:104`.
- **`AppIconCoriolis` ≠ `IconMedallion`** — project ships nine slug-keyed glyph icons; handoff `IconMedallion` is brass-disc + Forum monogram + astrolabe ticks + `glow`. Add `AppIconMedallion` (don't refactor `AppIconCoriolis`).
- **`AppAvatar` ≠ `Portrait`** — `AppAvatar` lacks the astrolabe tick ring used as character-identity primitive across sheet hero / combat tracker / GM crew. Either add a `astrolabe` shape prop or ship `AppPortrait` wrapping `AppAvatar`.
- **`AppDie`** API differs: handoff `hit`/`pushed` booleans, project unified `state: 'normal'|'hit'|'pushed'|'failed'` (project API is cleaner — document the mapping). Visual: project face is night-blue with brass stroke; handoff is brass-bevel gradient. `AppDie.vue:215` vs `primitives.jsx:L118-L123`.
- **`AppArabesqueCorner`** default color `brass`; handoff defaults to `brand-brass-deep`. Trivial. `AppArabesqueCorner.vue:8-11`.
- **`AppChip`** variant naming drift (`crimson` covers `--cond`; separate `AppConditionPill` exists). Document mapping; no functional gap.

### 3.3 Extras (project-only, keep)

`AppBadge`, `AppBanner`, `AppConditionPill`, `AppField`, `AppHeader`, `AppMobileDrawer`, `UserMenu`, `AppIcon`, `AppKbd`, `AppModal`, `AppPopover`, `AppTooltip`, `AppProgress`, `AppSavePulse`, `AppSegControl`, `AppSelect`, `AppSwitch`, `AppTextarea`, `AppDiePool` — all useful, not in handoff atom catalog.
